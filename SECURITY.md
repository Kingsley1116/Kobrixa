# Security policy / 安全政策

## English

### Supported versions

Security fixes target the latest published release, including the current prerelease while Kobrixa is in beta, and the current `main` branch. Older releases do not receive separate security backports. Include the exact version or commit in your report.

### Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Kingsley1116/Kobrixa/security/advisories/new). Do not disclose vulnerabilities in public issues or pull requests.

Include the affected version and component, prerequisites, minimal reproduction steps or a proof of concept, expected security behavior, and impact. For device issues, include OS, EV3 firmware and connection details. Remove credentials, collaboration invite codes, personal data and private project content.

Coordinate disclosure with maintainers in the private report while a fix is assessed and prepared. Reports are handled on a best-effort basis; no fixed response time is promised.

For ordinary bugs and usage questions, use the [issue forms](https://github.com/Kingsley1116/Kobrixa/issues/new/choose).

## 繁體中文

### 支援版本

安全修正以最新發布版本（beta 階段包含目前的預覽版本）與目前的 `main` 分支為目標，不會另行回補舊版。回報時請提供確切版本或 commit。

### 回報漏洞

請使用 [GitHub 私人漏洞回報](https://github.com/Kingsley1116/Kobrixa/security/advisories/new)，勿在公開 issue 或 pull request 揭露漏洞。

請附上受影響版本與元件、前置條件、最小重現步驟或概念驗證、預期安全行為與影響。裝置問題請另附作業系統、EV3 韌體與連線資訊。請移除憑證、協作邀請碼、個資與私人專案內容。

在評估與準備修正期間，請透過私人回報與維護者協調公開時程。維護者會盡力處理，但不承諾固定回覆時間。

一般錯誤與使用問題請使用 [issue 表單](https://github.com/Kingsley1116/Kobrixa/issues/new/choose)。
