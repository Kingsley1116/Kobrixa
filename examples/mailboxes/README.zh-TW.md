# 信箱

<a href="../README.zh-TW.md">所有範例</a> · <a href="./README.md">English</a>

建立具名信箱，準備 EV3 對 EV3 訊息傳遞。

## 專案

| 範例                                  | 學習內容                 | 硬體需求           |
| ------------------------------------- | ------------------------ | ------------------ |
| [mailbox-local](./mailbox-local/)     | 建立具名收件匣並輪詢     | 可選用第二台 EV3   |
| [paired-receiver](./paired-receiver/) | 接收文字與數字訊息       | 兩台藍牙配對的 EV3 |
| [paired-sender](./paired-sender/)     | 連線並傳送文字與數字訊息 | 兩台藍牙配對的 EV3 |
