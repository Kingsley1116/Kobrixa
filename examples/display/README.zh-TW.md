# 顯示

<a href="../README.zh-TW.md">所有範例</a> · <a href="./README.md">English</a>

學習文件化的 LCD 文字、字型、座標、線條與圓形操作，不需要連接馬達或感測器。

## 專案

| 範例                                                  | 學習內容                          | 硬體需求         |
| ----------------------------------------------------- | --------------------------------- | ---------------- |
| [display-write](./display-write/)                     | 使用 `LCD.Write` 顯示簡單黑色文字 | 顯示器           |
| [display-fonts](./display-fonts/)                     | Tiny、Small 與 Big 三種字型       | 顯示器           |
| [display-shapes](./display-shapes/)                   | 線條、同心圓與座標                | 顯示器           |
| [drawing-primitives](./drawing-primitives/)           | 像素、矩形、反相與實心圓          | 顯示器           |
| [double-buffer-animation](./double-buffer-animation/) | 整個畫面畫完才更新 LCD            | 顯示器           |
| [fractional-coordinates](./fractional-coordinates/)   | 小數座標轉為整數參數              | 顯示器           |
| [button-cursor](./button-cursor/)                     | 按鍵控制游標與雙緩衝動畫          | 顯示器與本體按鍵 |
