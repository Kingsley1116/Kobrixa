# 語言

<a href="../README.zh-TW.md">所有範例</a> · <a href="./README.md">English</a>

示範適用於所有 EV3 API 類別的 Basic Plus 來源語言行為。

Kobrixa 在布林情境中同時接受裸 `true`／`false` 與舊式帶引號的 `"True"`／`"False"`。

## 專案

| 範例                                          | 學習內容                             | 硬體需求 |

| [case-insensitive](./case-insensitive/)       | 混用大小寫的關鍵字、變數與 API       | 顯示器   |
| [text-and-math](./text-and-math/)             | 文字組合與數學函式                   | 顯示器   |
| [text-search](./text-search/)                 | 從 1 起算的文字搜尋與擷取            | 顯示器   |
| [compound-arithmetic](./compound-arithmetic/) | 複合賦值與保留小數的除法             | 顯示器   |
| [byte-logic](./byte-logic/)                   | 位元遮罩與十六進位格式               | 顯示器   |
| [byte-workbench](./byte-workbench/)           | 十六進位／二進位轉換、位元測試與位移 | 顯示器   |
| [local-functions](./local-functions/)         | 定義並呼叫本地 Function              | 顯示器   |
| [display-function](./display-function/)       | 型別化的數字與文字輸入參數           | 顯示器   |
