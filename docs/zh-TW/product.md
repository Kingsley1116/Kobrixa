# 產品規格

## 目的

Kobrixa IDE 為學生與創客提供可靠、容易理解的流程，將 EV3 原始碼轉成在實體機器人上執行的程式。產品優先追求短回饋週期、可採取行動的錯誤訊息、離線使用和可預期的實機行為，而不是提供大量僅部分支援的功能。

目前 v1 候選版已實作 Basic Plus 編輯與編譯、專案管理、USB／Wi-Fi transport 及遠端檔案管理。完整平台支援仍須完成 EV3 實機矩陣；發布簽章流程已整合，但須備妥正式憑證並通過外部驗證，才能宣稱下載檔已簽章。

## 主要使用者

- 從積木程式進階到文字程式的學生。
- 維護或擴充既有 `.bp` 機器人程式的創客。
- 需要在 Windows、macOS、Linux 重複設定範例與設備的指導者。

進階語言工具、教室設備群管理和雲端協作不是 v1 優先項目。

## v1 使用流程

1. 建立專案或開啟相容的 `.bp` 程式。
2. 使用語法高亮、支援 EV3 API 補全與行內診斷進行編輯；閱讀雙語解說，並選取適用的 Quick Fix。
3. 在本機建置原生 `.rbf` 成品。
4. 透過 USB HID 或 Wi-Fi 搜尋並連接 EV3。
5. 上傳、執行、停止或刪除程式。
6. 每個操作都顯示結構化結果，失敗時提供復原指引。

編輯器與編譯器必須能離線使用。Wi-Fi 用於連接 EV3，不作為雲端依賴。

## v1 需求

### 工作區與編輯器

- 開啟資料夾、`kobrixa.json` 專案或單一 `.bp` 檔案。
- 編輯多個專案檔案，且不遺失未儲存內容。
- 在頂部專案分頁切換多個專案，保留檔案分頁、草稿、游標、捲動位置及本次執行的復原歷史；左右方向鍵、Home／End 可切換專案分頁。
- 編譯或上傳期間可編輯其他專案，EV3 作業仍依序執行。關閉專案時可儲存、捨棄或取消；正常退出保留工作狀態，重新啟動後自動恢復專案與草稿。
- 為支援的 `.bp` 語法提供語法高亮、括號配對、跳至診斷、基本補全與格式化。
- 顯示建置與設備狀態，且不得隱藏詳細診斷。
- 所有診斷代碼提供繁體中文及英文離線解說，包含原因、處理步驟與原始訊息；官網[錯誤索引](/docs/diagnostics?lang=zh-TW)可依代碼查閱。
- 對可確定的語法缺口提供 Quick Fix：型別陣列的 `]`、行尾的 `)`、`For` 的 `=` 或 `To`，以及檔尾區塊結尾。由使用者明確選取後套用，每次可用一步 Undo 復原，並沿用草稿與儲存偏好；歧義或過期診斷不直接修改程式。

[快捷鍵與設定](keyboard-settings.md)

### 建置

桌面編譯在獨立 worker 執行，持續回報進度並支援協作式取消，主程序仍可處理設備與視窗事件。

- 編譯前驗證 manifest。
- 將支援的 `.bp`、include、module 和素材輸入編譯為 `KobrixaIR`，再產生原生 `.rbf`。
- 回傳具有穩定代碼與來源範圍的確定性診斷。
- 發生編譯錯誤時不得產生成功、可部署的成品。
- 支援取消；取消的建置不得取代上一個成功成品。

### 設備操作

- 搜尋 USB EV3，並連接使用者提供的 Wi-Fi 位址。
- 顯示目前 transport 與連線狀態。
- 上傳、執行、停止與刪除程式。部署時重新讀取 EV3 目錄，只有大小與校驗值皆符合的素材才略過；程式檔一律最後上傳。可在「設定 → EV3 與執行」關閉「略過未變更的素材」，完整重新上傳。
- 瀏覽遠端檔案、傳輸檔案或資料夾，並在批次傳輸前預覽衝突。
- 對停滯操作套用逾時，並區分權限、搜尋、連線、協定、傳輸和設備錯誤。

### 桌面發布

- 封裝 Windows x64 NSIS／ZIP、macOS Apple Silicon DMG 與 Linux x64 AppImage／tar.gz，並產生更新資訊及 SHA256SUMS.txt。
- 啟用 macOS 簽章時使用 Apple Developer ID 與公證。Windows 在 SignPath Foundation 核准且簽章驗證成功前，明確標示未簽章。
- Release 說明逐平台記錄實際簽章狀態；啟用後簽章失敗會保留未完成草稿供檢閱。
- Release 維持人工公開。安裝套件與自動更新已實作；可下載套件與簽章狀態以各個已發布 Release 為準。Intel Mac 套件仍不在目前範圍內。

下載與驗證方式請見[安裝與復原](../zh-TW/installation.md)及[程式碼簽章政策](../zh-TW/code-signing.md)。

## v1 非目標

- Bluetooth transport
- Blockly 或其他積木編輯器
- 雲端帳號、同步或協作
- 原始碼層級除錯器或模擬器
- Python、TypeScript 或 C++ 編譯
- 教室設備群管理
- 匯入支援 `.bp` 以外的專有專案格式

## 成功標準

只有在以下條件全部成立時，v1 才可驗收：

- 支援的舊版 `.bp` 程式不修改原始碼即可開啟、編譯，並在參考 EV3 上呈現等價的可觀察行為。
- 有效範例可在 Windows、macOS、Linux 建置成 `.rbf`。
- USB 與 Wi-Fi 上傳／執行流程在三個平台通過。
- 語法和語意錯誤能指出來源檔案與行／列範圍。
- 上傳期間中斷 EV3，系統會回報可復原錯誤，且不會顯示假成功。
- 應用程式不需要雲端帳號或持續網路連線即可安裝與使用。
- 最終下載檔保留完整檔案、權限、符號連結與原生 USB 模組，且宣稱的簽章或公證皆須在解壓後通過驗證。

相容性指行為等價，不是輸出逐位元相同。詳見[語言支援政策](../zh-TW/language-support.md)與[設備支援規格](../zh-TW/device-support.md)。
