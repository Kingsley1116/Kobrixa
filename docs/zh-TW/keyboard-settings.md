# 快捷鍵與設定

點選齒輪，或在 macOS 按 **Command+,**、Windows／Linux 按 **Ctrl+,** 開啟設定。調整立即生效，並保存在這台電腦。若出現保存失敗訊息，設定仍適用於本次使用期間，可點選「重試保存」。

## 快捷鍵

開啟「快捷鍵」分類，或先按 **Mod+K**，再於兩秒內按 **Mod+S**。**Mod** 在 macOS 代表 Command，在 Windows／Linux 代表 Ctrl。

| 操作                   | 預設快捷鍵               |
| ---------------------- | ------------------------ |
| 新增專案               | Mod+Shift+N              |
| 開啟專案               | Mod+O                    |
| 儲存                   | Mod+S                    |
| 全部儲存               | Mod+Shift+S              |
| 關閉目前檔案／設定分頁 | Mod+W                    |
| 下一個／上一個分頁     | Ctrl+Tab／Ctrl+Shift+Tab |
| 設定                   | Mod+,                    |
| 快捷鍵設定             | Mod+K，再按 Mod+S        |
| 切換檔案樹             | Mod+B                    |
| 切換診斷面板           | Mod+J                    |
| 切換 EV3 工具          | Mod+Shift+E              |
| 格式化文件             | Alt+Shift+F              |
| 下一個／上一個診斷     | F8／Shift+F8             |
| 編譯                   | Mod+Shift+B              |
| 在 EV3 執行            | F5                       |
| 停止／取消進行中的編譯 | Shift+F5                 |

執行快捷鍵沿用工具列的檢查條件及儲存、編譯、設備流程。長按不會重複啟動操作；不可用的命令也不會略過操作鎖定或對話框。

清單預設顯示所有 IDE 與 Monaco 編輯器命令，包括尚未設定按鍵的命令。每個命令都有中英文名稱與操作說明，說明顯示在命令名稱下方及快捷鍵修改對話框中，解釋操作效果，以及需要的命令參數或語言提供者。展開命令名稱可查看英文名稱、命令 ID、適用條件及預設按鍵。IDE 命令列在前方，其餘依目前介面語言排序。

搜尋可混用中英文名稱與說明、命令 ID 與多個關鍵字，也支援 `Cmd／Command／⌘`、`Ctrl／Control`、`Option／Alt／⌥`、`Shift／⇧` 及 `Mod` 等按鍵寫法。可搭配來源「IDE／編輯器」及狀態「已修改／未設定」篩選；未設定包含已解除的命令。切換語言會保留搜尋及正在修改的按鍵。

使用「按快捷鍵搜尋」可直接錄下想查詢的按鍵：單組會找出任一段含該按鍵的綁定，兩段則比對完整順序。錄製時不執行命令，也不會修改設定。「清除條件」可返回完整清單。

點選「修改」或「新增快捷鍵」，選擇「單組／兩段」，再按「開始錄製」。單組按下後立即可套用；兩段必須在第一組後兩秒內輸入第二組，逾時會保留預覽並要求重新錄製，不會自動改成單組。Escape 取消；錄製結束後可用 Tab 與 Enter 操作對話框。新綁定會取代該命令的預設快捷鍵，並保留原本的適用情境。

按鍵衝突或連按前綴重疊時，對話框會列出衝突命令、按鍵及原因。可直接修改或解除衝突項目；完成或取消修改後會回到原設定，保留已錄製的按鍵。可證明互斥的編輯器情境仍可共用按鍵，系統不會自動覆蓋其他命令。

每列「更多操作」提供「解除」與「還原預設按鍵」；解除後仍可透過其他介面執行命令。個別還原若有自訂按鍵衝突，也會要求先處理；「全部還原」則於確認後恢復所有命令。狀態區分預設、自訂、未設定及已解除。

系統保留快捷鍵及未搭配修飾鍵的文字輸入鍵不能作為自訂快捷鍵的第一組。編輯器命令在編輯器內生效，一般設定／搜尋欄位保留文字編輯行為。按鍵符號的提示提供完整名稱，工具列及按鈕提示會同步顯示目前有效的快捷鍵。

## 編輯器偏好

- **行號：** 顯示（預設）、相對行號或隱藏。
- **程式碼縮圖：** 預設關閉。
- **空白字元：** 選取範圍（預設）、不顯示或全部。
- **貼上時格式化：** 預設開啟。

調整不會重建編輯器或清除復原紀錄。既有字級、自動換行、縮排、語言、主題及布局設定仍可使用。

## 儲存

「自動儲存」與「儲存時格式化」皆預設關閉。

自動儲存可選擇停止輸入後，或離開編輯器時執行。延遲可選 500、1,000（預設）、2,000 或 5,000 毫秒。離開編輯器包含切換檔案、開啟其他面板及切換到其他應用程式；使用編輯器內的搜尋或補全視窗不算離開。

自動儲存只處理已開啟且有修改的檔案，不會格式化。啟用「儲存時格式化」後，手動儲存、全部儲存及編譯／執行前儲存會使用目前縮排大小及既有 Basic Plus 或 JSON 格式器；未支援的檔案類型直接保存原內容。開啟檔案的格式化修改可以復原。格式化或儲存失敗會停止該次儲存／編譯，保留未儲存工作。

原始檔與復原草稿依序寫入。寫入途中新增的輸入仍標記為未儲存，直到新內容實際存入磁碟。切換專案、移動或刪除檔案會等待進行中的寫入；編譯前仍會儲存未開啟檔案的復原草稿。自動儲存失敗會顯示錯誤，不會無限重試；可再次編輯或手動儲存以重試。既有草稿復原及未儲存分頁確認流程仍可使用。
