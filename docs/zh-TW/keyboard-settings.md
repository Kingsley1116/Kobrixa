# 快捷鍵與設定

點選齒輪，或在 macOS 按 **Command+,**、Windows／Linux 按 **Ctrl+,** 開啟設定。一般偏好立即生效，並保存在這台電腦。若一般偏好出現保存失敗訊息，仍適用於本次使用期間，可點選「重試保存」。設備參數與更新偏好則於成功保存後生效。

## 快捷鍵

開啟「快捷鍵」分類，或先按 **Mod+K**，再於兩秒內按 **Mod+S**。**Mod** 在 macOS 代表 Command，在 Windows／Linux 代表 Ctrl。

| 操作                   | 預設快捷鍵               |
| ---------------------- | ------------------------ |
| 新增專案               | Mod+Shift+N              |
| 開啟專案               | Mod+O                    |
| 快速開啟專案檔案       | Mod+P                    |
| 跨檔案搜尋             | Mod+Shift+F              |
| 儲存                   | Mod+S                    |
| 全部儲存               | Mod+Shift+S              |
| 關閉目前檔案／設定分頁 | Mod+W                    |
| 下一個／上一個分頁     | Ctrl+Tab／Ctrl+Shift+Tab |
| 設定                   | Mod+,                    |
| 快捷鍵設定             | Mod+K，再按 Mod+S        |
| 切換檔案樹             | Mod+B                    |
| 切換診斷面板           | Mod+J                    |
| 切換 EV3 工具          | Mod+Shift+E              |
| 格式化文件             | Alt+Shift+F              |
| 下一個／上一個診斷     | F8／Shift+F8             |
| 編譯                   | Mod+Shift+B              |
| 在 EV3 執行            | F5                       |
| 停止／取消進行中的編譯 | Shift+F5                 |

執行快捷鍵沿用工具列的檢查條件及儲存、編譯、設備流程。長按不會重複啟動操作；不可用的命令也不會略過操作鎖定或對話框。

清單預設顯示所有 IDE 與 Monaco 編輯器命令，包括尚未設定按鍵的命令。每個命令都有中英文名稱與操作說明，說明顯示在命令名稱下方及快捷鍵修改對話框中，解釋操作效果，以及需要的命令參數或語言提供者。展開命令名稱可查看英文名稱、命令 ID、適用條件及預設按鍵。IDE 命令列在前方，其餘依目前介面語言排序。

搜尋可混用中英文名稱與說明、命令 ID 與多個關鍵字，也支援 `Cmd／Command／⌘`、`Ctrl／Control`、`Option／Alt／⌥`、`Shift／⇧` 及 `Mod` 等按鍵寫法。可搭配來源「IDE／編輯器」及狀態「已修改／未設定」篩選；未設定包含已解除的命令。切換語言會保留搜尋及正在修改的按鍵。

使用「按快捷鍵搜尋」可直接錄下想查詢的按鍵：單組會找出任一段含該按鍵的綁定，兩段則比對完整順序。錄製時不執行命令，也不會修改設定。「清除條件」可返回完整清單。

點選「修改」或「新增快捷鍵」，選擇「單組／兩段」，再按「開始錄製」。單組按下後立即可套用；兩段必須在第一組後兩秒內輸入第二組，逾時會保留預覽並要求重新錄製，不會自動改成單組。Escape 取消；錄製結束後可用 Tab 與 Enter 操作對話框。新綁定會取代該命令的預設快捷鍵，並保留原本的適用情境。

按鍵衝突或連按前綴重疊時，對話框會列出衝突命令、按鍵及原因。可直接修改或解除衝突項目；完成或取消修改後會回到原設定，保留已錄製的按鍵。可證明互斥的編輯器情境仍可共用按鍵，系統不會自動覆蓋其他命令。

每列「更多操作」提供「解除」與「還原預設按鍵」；解除後仍可透過其他介面執行命令。個別還原若有自訂按鍵衝突，也會要求先處理；「全部還原」則於確認後恢復所有命令。狀態區分預設、自訂、未設定及已解除。

系統保留快捷鍵及未搭配修飾鍵的文字輸入鍵不能作為自訂快捷鍵的第一組。編輯器命令在編輯器內生效，一般設定／搜尋欄位保留文字編輯行為。按鍵符號的提示提供完整名稱，工具列及按鈕提示會同步顯示目前有效的快捷鍵。

## 快速開檔與跨檔案搜尋

按 **Mod+P**，以檔名或路徑篩選目前專案的檔案。加上 `:行號` 或 `:行號:欄號` 可直接跳轉，例如 `main:20:5`。使用方向鍵選擇結果，按 **Enter** 開啟，或按 **Escape** 返回而不開啟檔案。開啟既有分頁會保留未儲存內容與復原紀錄。可在快捷鍵設定中修改按鍵。

按 **Mod+Shift+F**，搜尋目前專案的 Basic Plus（`.bp`、`.bpi`、`.bpm`）與 JSON 檔案。搜尋面板包含尚未開啟的檔案、編輯器中的未儲存內容與復原草稿。搜尋依照輸入的文字比對，可透過「區分大小寫」與「全字相符」縮小範圍。每筆結果顯示檔案、行號與符合文字，點選後會開啟檔案並選取該段文字。外部內容變更後，可按「重新搜尋」更新結果。切換專案會清除搜尋條件；較早查詢或專案的延遲回覆不會覆蓋目前結果。

輸入取代文字並選擇「預覽取代」，先檢查受影響的檔案再套用。取代文字會原樣使用，包含 `$` 等字元。套用後，受影響的檔案會開啟為已修改分頁，並遵循原有儲存設定；關閉自動儲存時，需自行儲存才會寫入來源檔案。每個檔案可分別復原。若預覽後檔案內容已變更，請重新搜尋並檢查新的預覽再取代。結果不完整時暫時無法取代，請調整搜尋文字或檢查略過的檔案。搜尋會略過建置輸出、隱藏路徑、素材、相依套件、符號連結，以及超過 1 MiB 的檔案；每次最多搜尋 5,000 個檔案、16 MiB 的檔案與編輯器內容，並顯示 2,000 個結果。

## 診斷解說與 Quick Fix

按 **Mod+J** 開啟診斷面板，再選取問題，即可閱讀原因、處理步驟、範例及原始編譯器訊息。所有診斷代碼均有繁體中文及英文解說，離線也能閱讀；切換介面語言後立即更新。「在官網查看此錯誤」會開啟[錯誤索引](https://kobrixa.com/docs/diagnostics?lang=zh-TW)的對應內容，網站可依代碼或關鍵字搜尋，並按診斷家族篩選。

有確定的修正方式時，可點選解說內的修正按鈕，或將游標移至錯誤處，使用編輯器燈泡／**Mod+.** Quick Fix 命令；按鍵可在快捷鍵設定中調整。目前支援補上型別陣列的 `]`、右括號 `)`、`For` 的 `=` 或 `To`，以及補齊檔尾缺少的區塊結尾。右括號會插在行尾註解之前，巢狀區塊結尾則一次補齊。

每次修正可用一步復原，並會重新分析。修正沿用一般自動儲存與草稿設定；關閉自動儲存時，需自行儲存才會寫入來源檔。只有目前有效的分析結果能提供修正；檔案、專案或磁碟內容已改變時，舊修正會被拒絕。修改後仍可閱讀先前的建置診斷，但不能使用過期位置套用修正。歧義語法、未閉字串、陣列索引缺少括號及錯配區塊會提供解說，不提供 Quick Fix。

## 編輯器偏好

- **行號：** 顯示（預設）、相對行號或隱藏。
- **程式碼縮圖：** 預設關閉。
- **空白字元：** 選取範圍（預設）、不顯示或全部。
- **貼上時格式化：** 預設開啟。

調整不會重建編輯器或清除復原紀錄。既有字級、自動換行、縮排、語言、主題及布局設定仍可使用。

## 儲存

「自動儲存」與「儲存時格式化」皆預設關閉。

自動儲存可選擇停止輸入後，或離開編輯器時執行。延遲可選 500、1,000（預設）、2,000 或 5,000 毫秒。離開編輯器包含切換檔案、開啟其他面板及切換到其他應用程式；使用編輯器內的搜尋或補全視窗不算離開。

自動儲存只處理已開啟且有修改的檔案，不會格式化。啟用「儲存時格式化」後，手動儲存、全部儲存及編譯／執行前儲存會使用目前縮排大小及既有 Basic Plus 或 JSON 格式器；未支援的檔案類型直接保存原內容。開啟檔案的格式化修改可以復原。格式化或儲存失敗會停止該次儲存／編譯，保留未儲存工作。

原始檔與復原草稿依序寫入。寫入途中新增的輸入仍標記為未儲存，直到新內容實際存入磁碟。切換專案、移動或刪除檔案會等待進行中的寫入；編譯前仍會儲存未開啟檔案的復原草稿。自動儲存失敗會顯示錯誤，不會無限重試；可再次編輯或手動儲存以重試。既有草稿復原及未儲存分頁確認流程仍可使用。

## 外部變更與本機歷史

預設在視窗可見時，Kobrixa 約每兩秒檢查開啟專案的外部變更，回到應用程式時也會檢查。來源／JSON 檔案的修改、新增及刪除會更新檔案樹與語言分析。管理檔案或有鎖定該專案的操作時，檢查會等待。

沒有本機修改的開啟檔案會自動載入磁碟版本，保留編輯位置，並可復原這次內容替換。若編輯器與磁碟都有變更，提示列會暫停該檔案的自動儲存。「比較變更」會並排顯示磁碟版本與你的修改，可選擇「使用磁碟版本」、明確「以本機內容儲存」，或關閉視窗繼續編輯。寫入前會再次比對磁碟版本；若外部再次修改，需要重新比較。全部儲存、編譯及執行遇到所需檔案有未解決衝突時會停止。外部刪除的開啟檔案仍保留編輯器內容，可明確重新建立，復原草稿也會保留到重新啟動後。沒有記錄磁碟版本的舊草稿在儲存前同樣需要比較。

點選編輯器上方的「本機歷史」可預覽過去內容。「還原到編輯器」會套用可復原的修改，並遵循目前的儲存設定，包含自動儲存；不會直接略過衝突或強制寫入。歷史位於應用程式的本機使用者資料目錄，不寫入專案，重新啟動後仍保留。Kobrixa 記錄儲存版本及偵測到的外部變更前後內容；兩次檢查之間已被取代的外部版本無法由此功能恢復。

歷史預設最多保留 30 天、每檔案 50 個版本，每工作區總容量上限為 50 MiB。預設超過 2 MiB 的單一版本不會記錄；連續相同內容會去重，達到限制時較早版本可能提前移除。在 Kobrixa 內重新命名或移動檔案時會一併保留歷史；外部重新命名視為刪除與新增。本機歷史不能取代獨立的專案備份。

可在「**設定 → 檔案與歷史**」調整以下偏好，適用於本機所有專案，重新啟動後仍保留。設定保存成功後套用；若保存失敗，沿用原設定並提供重試。

| 設定             | 選項                 | 預設   |
| ---------------- | -------------------- | ------ |
| 外部變更偵測     | 開啟／關閉           | 開啟   |
| 外部變更檢查間隔 | 1、2、5、10 秒       | 2 秒   |
| 自動載入外部變更 | 開啟／關閉           | 開啟   |
| 記錄本機歷史     | 開啟／關閉           | 開啟   |
| 歷史保留天數     | 7、30、90 天         | 30 天  |
| 每檔案版本數     | 20、50、100、200     | 50     |
| 單一版本大小上限 | 1、2、5、10 MiB      | 2 MiB  |
| 每工作區歷史容量 | 20、50、100、200 MiB | 50 MiB |

關閉外部變更偵測會停止背景及回到視窗時的檢查，儲存時仍會檢查磁碟版本衝突。關閉自動載入後，即使開啟檔案沒有本機修改，也會保留編輯器內容並提示比較；重新開啟自動載入不會解除已有衝突。關閉本機歷史會停止新增快照，既有版本仍可在保留限制內查看。停止記錄時仍可調整保留限制；降低保留天數、版本數或工作區容量，會在下次歷史操作時套用，可能移除較早版本。單一版本大小上限只適用於新記錄：超過上限的快照不會記錄，既有較大版本不會因此刪除。

## 搜尋與還原設定

「全部設定」集中顯示一般、編輯器、儲存、檔案與歷史、布局、EV3 與更新偏好。搜尋可混用中英文名稱、說明、設定 ID 與多個關鍵字；搜尋時切到全部分類，也可再選分類縮小範圍。「只看已修改」以保存的偏好與預設值比較，跟隨系統主題不會因當下系統外觀而改變修改狀態。

每項顯示預設值；已修改的項目可個別還原。若還原後從篩選清單消失，焦點回到搜尋欄。未啟用的相依選項仍可搜尋，並說明啟用條件；例如自動儲存延遲需要先選擇「停止輸入後」。快捷鍵沿用自己的搜尋與還原介面。

## 外觀與進階編輯器偏好

主題新增「依系統設定」，即時跟隨系統深淺外觀；頂部主題按鈕會切換目前有效主題並保存為明確的深色或淺色選擇。初始預設仍為深色。

行距提供緊湊（1.4 倍）、標準（沿用字級 × 25/16）及寬鬆（1.8 倍）。游標可選直線、方塊或底線，並獨立切換閃爍。目前行提示可關閉、只顯示程式碼行，或包含行號區。

括號配色、括號／縮排輔助線、摺疊、頂端固定區塊（最多三行）、括號／引號自動補齊、自動補全、滑鼠懸停說明與函式參數提示皆預設開啟。平滑捲動與捲動超過最後一行預設關閉。關閉自動補全仍可手動叫出補全。

減少動態效果生效時，平滑捲動與游標閃爍暫停，原有偏好會保留。上述調整即時套用，保留編輯器內容、游標與復原紀錄。

## EV3 與執行偏好

「略過未變更的素材」預設開啟。部署前會重新讀取 EV3 目錄，比對素材大小與校驗值；缺少或無法確認的素材會重新上傳，程式檔一律最後上傳。關閉此設定後，會完整重新上傳全部檔案。比對時發生連線錯誤會停止部署。

連線方式預設 USB，之後記住 USB／Wi-Fi 選擇；更換偏好不會中斷既有連線。「記住 Wi-Fi 位址」預設關閉，啟用後保存最後成功手動輸入並連線的位址；關閉會清除保存值，但保留當次輸入。

編譯診斷可設為不自動展開、錯誤時展開（預設），或錯誤／警告時展開。設備操作失敗時自動展開活動面板預設開啟；等待連線的必要提示始終保留。

| 設備參數                | 選項                        | 預設                            |
| ----------------------- | --------------------------- | ------------------------------- |
| USB 自動重連            | 開啟／關閉                  | 開啟                            |
| USB 重試間隔            | 漸進式、固定 1／2／5／10 秒 | 漸進式：1、2、5 秒，之後每 5 秒 |
| USB 嘗試上限            | 3／5／10 次、不限           | 不限                            |
| Wi-Fi 建立 TCP 連線逾時 | 3／5／10／30 秒             | 5 秒                            |
| Wi-Fi 握手逾時          | 1／3／5／10 秒              | 3 秒                            |

第一次重連立即嘗試，計入次數上限；耗盡後停止並提示手動連線。關閉自動重連立即取消等待或恢復中的連線。間隔與上限變更適用於下一輪恢復，Wi-Fi 逾時變更適用於下一次連線。USB 仍依序號辨識設備、驗證已上傳內容，重連不會自動執行程式。

一般偏好即時生效並保存在這台電腦；設備參數由主程序保存，成功後才生效。保存失敗時維持既有設備參數，可重試。設定為本機所有專案共用。
