# 感測器曲線與校正

在 Stage 3 開發分支，先從 **插件工具 → EV3** 連接裝置，再開啟 **插件工具 → 感測器工具**。這是可選的內建功能，一般使用者可在插件設定切換，不需要開發者模式。舊的 **EV3 工具 → 監測 → 曲線與校正** 屬於先前實作，正逐步撤除。若新功能不可用或資料匯入仍待完成，請依其復原狀態處理；開啟舊介面不會繞過這個狀態。最多選擇四個通道，來源包括本機輸入埠 1–4 的數值通道與 A–D 馬達角度。記錄期間固定通道及校正參數，並禁止切換感測器模式。

每個通道各有一張圖與獨立 Y 軸，共用相對時間軸。即時顯示最近 60 秒，停止後顯示完整記錄。「放大圖表」提供可用鍵盤操作的時間滑桿。可切換「原始／校正後」數值，並在「已存記錄」使用「查看」與「比較」，將兩次實驗依開始時間對齊，以實線與虛線疊圖。只有相同來源定義及單位才疊圖；歷史數值始終使用該次保存的校正參數。

## 記錄與儲存

切換分頁、收起側欄、隱藏或最小化視窗仍會持續記錄。插件狀態區顯示記錄狀態，並提供主機管理的「停止」及「開啟」操作；使用「開啟」返回感測器工具。可見監測面板與記錄共用主程序的同一個排程，每次讀取完成後等待 500 ms，畫面另外顯示實際間隔。上傳、執行、停止與檔案操作優先。時間是主機收件時間及主程序單調時鐘的相對時間，不是硬體精確採樣時間。

設備忙碌、暫時讀取錯誤或無效值會留下缺口，不補零、不重複舊值，也不跨缺口連線。確認來源移除、型別／模式／單位改變、斷線或 session 更換、電腦睡眠時，自動結束並標示原因。恢復連線後，須手動開始新記錄與重新套用校正。

每次最多 30 分鐘或 3,600 組快照，先到上限即停止。最多保存 50 次；滿額時先手動刪除。新記錄由主機的插件記錄儲存區管理，每五秒提交一次檢查點。原有 `userData/sensor-lab` 記錄與校正設定檔只匯入一次，原檔保留。匯入未完成或失敗時，必須先完成匯入或處理復原狀態，新資料庫才會開放。意外退出後恢復最後檢查點，標示中斷，不自動續錄。儲存失敗時，請分清最後已提交的檢查點與尚未儲存的尾段。核心復原只會提供仍可重試的資料；程序中斷後，不能保證恢復只存在記憶體中的樣本。停止後依復原入口處理。關閉程式、斷線及安裝更新會等待必要的停止與儲存工作，未解決時保持阻擋。停用此功能也會結束記錄並執行最後儲存；電腦睡眠後喚醒不會自動續錄。

「匯出 CSV」使用原生儲存對話框，輸出 UTF-8 BOM。每個通道每次快照各一列，包含記錄名稱、收件時間、相對毫秒、來源、模式、原始／輸出單位、原始值、校正值及狀態；缺值欄位留空。取消不產生檔案，失敗不回報成功。單次匯出上限為 8 MiB；超過時須明確選擇較小的時間區間，不會默默截斷資料。

## 校正與程式碼

在「校正」選擇一個通道，啟用兩點換算後可擷取新鮮讀值或手動輸入實測 A／B，再設定目標值（預設 0–100）。支援反向映射與超出範圍的外插，不截斷結果。「將目前值歸零」扣除當下換算值；未啟用兩點時則扣除原始值。記錄前按「套用校正」，也可儲存命名設定檔供之後手動套用。

公式為 `targetA + (x − sourceA) × (targetB − targetA) / (sourceB − sourceA) − zeroOffset`，依此運算順序逐步採用 float32 精度。拒絕非有限、過期、重合或無法表示的參數；無效或溢位結果保留為缺值。這不修改感測器韌體，也不重設馬達計數。

「BASIC Plus 程式」提供完整範例預覽與複製，不覆寫編輯中的程式。感測器範例會檢查型別、明確設定校正時的模式、等待就緒、讀取 SI、驗證數值、換算並顯示結果；馬達使用 `Motor.GetCount`。

`Sensor.ReadSIValue(port, index)` 不切換模式，讀取目前模式的 SI 浮點數。埠沿用 1–16 編碼，通道索引為 0–7；SI 指韌體提供的模式單位。不合法常數會產生編譯診斷；動態參數不合法、通道不存在、裝置未就緒、讀值無效或讀取期間型別／模式改變時回傳 `NaN`。實作依據 [LEGO Firmware Developer Kit 的輸入埠指令](https://assets.education.lego.com/v3/assets/blt293eea581807678a/blt469be1e11ad37696/5f880384f71916144453a49f/lego-mindstorms-ev3-firmware-developer-kit.pdf?locale=en-us)。
