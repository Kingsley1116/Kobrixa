# 馬達測試

Stage 3 整合草稿：本頁說明公開的馬達測試插件。產品啟用及舊監測卡片移除仍待整合驗證；此分支尚非已發行安裝版。

先在設備工具連接 EV3，再開啟 **插件工具 → 馬達測試**，按「使用目前連線」選取連線，並選擇 **A–D** 輸出埠。開啟面板、重新整理或啟用插件都不會自動連線或運轉，不需要建立專案或撰寫程式。

僅支援已辨識的本機 EV3 大型／中型馬達。程式執行中、其他輸出運轉、Sensor Lab 記錄中、設備提供者不可用、讀值失效或沒有控制權時，都不能開始；協作檢視者也不能啟動運轉。「重新整理可用性」只更新目前狀態，不重試上次動作。

## 操作

每個埠分別保留參數草稿，可選點動、定時或相對角度。未填完或超出範圍的數值會在欄位旁標示並阻止開始。功率是輸出百分比，不是固定轉速。

- 功率預設 20%，可設 1–100%。
- **點動**：按住「按住正轉」或「按住反轉」，也可在取得焦點的按鈕上按住 Space／Enter。放開或取消按住就要求停止；方向由按住的按鈕決定，單次最多十秒。
- **定時**：預設一秒，可設 0.1–5 秒，依所選方向運轉。
- **相對角度**：預設 90°，可設 1–3,600 的整數角度，依所選方向運轉；十秒內未完成會逾時。
- 一般結束可選煞車或滑行。「停止（煞車）」即使其他欄位有無效草稿仍可要求煞車。滑行可能繼續轉動，韌體煞車也不是機械鎖定。

面板分別顯示執行階段、運動結果、指令送出情況與停止確認；有讀值時才顯示時間／角度進度。未知讀值不會變成零。編碼器讀值不包含齒輪、打滑或機構間隙補償，測試不清除硬體計數。

切換埠會保留各埠草稿。同一工作視窗內隱藏、關閉再開啟面板，可保留有容量上限的參數與未輸入完的數字，但不恢復運轉、控制權或舊操作。插件程序／資源更換及工作視窗退役會清掉草稿；它們不是持久設定，重啟程式後不保留。

## 停止與復原

釋放、隱藏、關閉面板或視窗、失焦、失去控制權、睡眠、停用與插件失敗都會要求停止。重新開啟、喚醒、重連或重新啟用都不續跑。停止要求、主程序讀回確認與實體停止是不同觀察；傳輸中的交換及韌體排程可能延後結果。

若啟動回覆遺失，插件只查詢原操作，不再送一次啟動。無法確認停止時，介面保留明確的未知結果，可按「開啟核心復原」查看主程序保存的證據。停止或儲存尚未解決時，正常斷線／退出可能受阻；程序結束或強制退出不代表馬達已確認停止。

測試期間獨占設備，不能交錯執行其他程式、部署、遠端檔案修改、模式變更或記錄，仍可編輯本機原始碼。既有 EV3 有限運轉期限、臨時程式清理與核心復原繼續負責設備安全；插件不取代它們。清理只移除自己的臨時程式，不刪除使用者專案。

## 可用性與驗收

馬達測試交付後是預設啟用、可獨立開關的內建插件，與設備提供者的開關分開。停用會停止其工作；重新啟用只恢復可用性。安全模式若抑制插件程序，面板會顯示不可用，核心復原仍可使用；請依插件設定中的說明明確恢復。

[實機清單](../../tests/hardware/motor-test.md)分別記錄 USB／Wi-Fi、作業系統、馬達類型、乾淨安裝與人工無障礙驗收。軟體測試、打包檢查與假設備的原生視窗測試不能替代實機結果，未執行的項目仍標為待驗證。
