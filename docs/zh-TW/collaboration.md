# 雲端協作

> **候選版本。** 雲端協作自 `v0.1.0-v1-candidate.12` 起納入桌面版本。預設服務為 `https://collab.kobrixa.com`。此頁描述目前實作；原始 `.12` 桌面版本不會保存房間恢復憑證。

透過 Kobrixa 營運的協作服務，多人可以同時編輯同一個 Kobrixa 專案。不需要帳號：主持人開啟房間並分享邀請碼，其他人輸入邀請碼，以及主持人選擇設定的房間密碼，即可加入。所有人看到相同的檔案、游標與聊天內容；同一時間只有一人能控制 EV3。

## 開啟與加入房間

**主持人：**開啟專案後，點擊頂部「協作」入口，再按「開啟房間」，於對話框輸入顯示名稱。可在對話框設定房間密碼，也可以留白。房間標頭會顯示 `ABCD-EFGH-JK23` 格式的邀請碼，把它分享給要邀請的人。

**來賓：**點擊頂部「協作」與「加入房間」，輸入邀請碼與顯示名稱；若主持人有設定房間密碼，也需輸入密碼後加入。歡迎畫面即可加入，不必先開啟本機專案或連接 EV3；專案內容會從房間同步過來。

- 顯示名稱最多 40 個字元；每個房間最多同時在線 16 個身分，離線成員不占名額。同一身分的新連線會取代舊視窗，舊視窗停止重連。
- 未設定密碼時，持有邀請碼即可加入；設定密碼後則兩者都需要。請只分享給要邀請的人。
- 房間密碼區分大小寫、保留空白，最多 128 個字元。服務端只儲存加鹽的密碼驗證值，不儲存密碼原文。
- 恢復憑證只由主程序保存，以原子寫入方式存入限目前使用者讀寫的檔案；不使用鑰匙圈，也不保存房間密碼。可從最近房間一鍵返回，由伺服器恢復原身分及目前角色。舊版從未保存的主持憑證無法憑名稱或密碼找回，請開啟保留的專案並建立新房間。
- 房間存取權杖由服務簽署，有效期限為 7 天，可透過保存的恢復憑證更新。

## 角色

| 角色   | 可執行的操作                                                     |
| ------ | ---------------------------------------------------------------- |
| 主持人 | 編輯者可做的一切，另可變更參與者角色及移除參與者                 |
| 編輯者 | 編輯檔案、建立／重新命名／刪除檔案、在聊天中發言；來賓的預設角色 |
| 檢視者 | 可觀看編輯過程及聊天發言，但不能編輯檔案或取得 EV3 控制權        |

被移除的參與者會立即斷線，其存取權與恢復憑證也會失效。

角色變更時，該參與者會重新連線並載入房間已確認的文件狀態。檢視者期間被拒絕的編輯會被捨棄，不會在升為編輯者後重新送出。

## 共同編輯

`.bp`、`.bpi`、`.bpm` 與 `.json` 專案檔可即時共同編輯。編輯器會顯示每位參與者的游標與選取範圍，並標示名稱與代表色。檔案樹同樣共享：建立、重新命名或刪除檔案都會同步給所有人。

共享專案最多 200 個檔案，每個檔案最多 1 MiB，全部共享文字合計最多 8 MiB（以 UTF-8 計算）。資料夾不計入檔案數量。分享前會列出支援格式、預計分享及超出限制或格式不支援的檔案。同步錯誤提供重試入口。

斷線與初始同步期間，編輯、檔案操作及聊天傳送會暫停，完成同步後才恢復。同時發生的共享文字編輯會由 Yjs 自動合併。本機磁碟寫入仍會檢查檔案版本；需要處理的寫入錯誤或外部變更衝突會由應用程式提示。

## 檔案存放位置

- **主持人：**編輯內容寫入主持人自己的專案資料夾，與一般使用相同。
- **來賓：**專案會鏡像到應用程式使用者資料目錄中的 `<userData>/collab/<room>/`。來賓可以在這個鏡像中建置、使用模擬器，並在持有設備控制權時上傳到自己的 EV3。

主持人返回時會開啟原本分享的專案，不會改用目前選取的其他專案；原路徑不存在時需重新選擇。重新加入前若發現與上次同步基準不同的本機內容，可選擇「保留副本後加入」或「取消」。副本包含未儲存草稿，保存成功前不會覆寫本機檔案。來賓鏡像會標示「共享」或「已離線」，並提供「另存共享專案副本」。

收合或切換面板只改變畫面。「離開房間」先保存草稿及完成本機寫入，只讓自己離線；尚未確認同步的修改會先另存副本，寫入失敗則留在房間重試。主持人可從房間選單選擇「結束房間」並確認，讓所有人斷線且房間失效，本機專案保留。主持人離線不會自動轉移主持權。

## 設備控制權

為避免多人同時操作同一台 EV3，只有持有設備控制權的參與者能上傳、執行或部署程式、開始馬達測試、管理 EV3 檔案及切換感測器模式。控制權預設屬於主持人；其他參與者可以提出請求，由主持人授予或收回。

無論控制權在誰手上，任何人都可以停止正在執行的程式。

## 聊天

協作面板內建純文字聊天，房間標頭持續顯示。每則訊息最多 2,000 個字元，房間保留最近 500 則訊息。檢視者也能發言。作者與時間由伺服器填入，以保存的訊息 ID 避免重送重複；確認成功後才清除草稿。草稿在離開與重開程式後保留，向上閱讀不會被強制捲回底部，可按「查看新訊息」返回。只有視窗可見且位於底部時才標記已讀。

## 工具分區

頂部「協作」與「EV3」各自獨立，共用右側空間；再次點擊目前入口即可收合，連線、設備工作、分頁及捲動位置都保留。EV3 面板包含連線、監測與 EV3 檔案；成員管理及控制權請求集中於協作。「操作紀錄」移至底部，與「診斷」並列。右側預設 360 px，可調整 320–520 px，窄視窗使用覆蓋面板。既有 EV3 快捷鍵保留，另提供可自訂的協作命令。

## 隱私與資料

- 房間使用期間，專案檔案、聊天訊息與顯示名稱等內容會儲存在協作服務上；連續 7 天沒有任何連線後自動刪除。
- 服務在 Cloudflare 上執行，因此原始碼會經過 Cloudflare 的網路。
- 請勿公開張貼邀請碼或房間密碼；能加入房間的人都能讀取專案，以編輯者身分加入時也能修改專案。
- 應用程式只連線到設定的協作服務來源；Content-Security-Policy 只允許該來源，不允許其他協作端點。

不得交由第三方服務處理的內容，請不要透過協作功能分享。

## 開發者說明

預設服務為 `https://collab.kobrixa.com`。啟動桌面應用程式前設定環境變數 `KOBRIXA_COLLAB_URL` 即可改用其他服務，例如本機服務：

```sh
cp apps/collab/.dev.vars.example apps/collab/.dev.vars   # 接著設定 COLLAB_SECRET
pnpm --filter @kobrixa/collab dev
KOBRIXA_COLLAB_URL=http://localhost:8787 pnpm dev
```

`COLLAB_SECRET` 是簽署房間權杖用的 HMAC 金鑰，本機使用任意夠長的隨機字串即可；`.dev.vars` 已被 Git 忽略。若 `wrangler dev` 顯示的位址與範例不同，請改用實際位址。服務邊界詳見[架構與公共契約](../zh-TW/architecture.md#雲端協作)。

編碼後的 Yjs 文件及單一 WebSocket 訊息上限為 16 MiB，以限制同步與歷史資料的額外用量；超大的更新會在接受前被拒絕。這些服務限制讓房間快照維持在平台的訊息與記憶體限制內。

執行 `pnpm build:core && pnpm test:collab:live` 可使用兩個客戶端測試真實本機 Worker，涵蓋無密碼與有密碼房間、錯誤密碼、持久化身分與角色恢復、檔案鏡像、編輯、聊天、控制權、角色變更、移除成員及 Worker 重啟後的資料保留。執行 `KOBRIXA_SMOKE_COLLAB_LINKED=1 pnpm test:desktop:smoke` 可驗證整合後的桌面操作流程；兩者皆使用本機測試資料。

部署服務後，執行 `pnpm test:collab:remote https://collab.kobrixa.com` 可對指定服務驗證相同的雙客戶端流程。測試會建立兩個僅含測試檔案與聊天內容的房間，結束主要測試房間後關閉所有客戶端；剩餘測試房間依閒置七天政策自動刪除。此模式會以全新客戶端確認伺服器狀態及被撤銷的存取權仍然有效，不會重啟已部署的 Worker。必須明確指定服務來源；HTTP 僅允許用於迴路位址。

## 驗收狀態

候選版本包含自動化單元、本機 Worker 與 Electron 整合測試。預設公開服務已於 2026-10-08 更新，並通過包含選填房間密碼的雙客戶端線上流程驗證。macOS 版面矩陣涵蓋 980×650、1420×900 視窗，320／360／520 px 面板，中英文、深淺主題及 100%／125% 縮放；各平台打包另由 CI 驗證。實體 EV3 驗收仍須另外執行，協作測試不代表完成實機驗收。

新桌面端以 `X-Collab-Capabilities: resume-v1` 啟用新增的恢復回應欄位。需先部署相容 Worker，再發佈桌面端；沒有此標頭時，保留 `.12` 嚴格 schema 所需的原回應格式。
